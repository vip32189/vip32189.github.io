# Bolsillo claro

Aplicación PWA para organizar dinero en pesos colombianos. Permite agregar ingresos y repartirlos entre **Ocio 🎮**, **Ahorros 🪙** y **Emprendimiento 👨‍🏭**. Ocio incluye el desglose de **Alimento 🍔**, **Productos 🛍️** y **Juegos 🎮**.

## Funciones

- Distribución automática en tres partes iguales.
- Desglose de Ocio en 25% / 50% / 25%.
- Edición individual de cada categoría.
- Persistencia local en el dispositivo.
- Diseño responsive para móvil y escritorio.
- PWA instalable en Android con soporte offline básico.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

La aplicación se abrirá en `http://localhost:3000`.

## Publicación

El proyecto se publica automáticamente mediante GitHub Actions en GitHub Pages cada vez que se actualiza la rama `main`.
